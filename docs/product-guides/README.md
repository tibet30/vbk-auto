# 产品操作指引库

按“一个产品（或一条产品线）一个目录”组织，供运营、司机、财务、管理员培训与日常查阅；后续新增产品文档都放在这里。

## 目录约定

```text
docs/product-guides/
  README.md                      # 本索引
  _shared/guide_docx.py          # 共用 docx 渲染器（版式，不含业务文案）
  <产品类型>-<线路或区域>/
    README.md                    # 本篇说明与维护方式
    产品操作指引（...）.docx      # 正式文档（可导入飞书）
    问题记录.md                  # 走单发现的问题、状态与修复记录
    assets/                      # 按流程编号的后台/小程序截图
    content.py / build_doc.py    # 文档内容与生成脚本
```

## 编写口径

- 示例要具体：固定一个产品、一个订单号、一套日期与金额，全文可对照。
- 每个环节写清：谁来做、入口在哪、做什么、看什么、完成标志、出错怎么办。
- 截图必须标明角色与环节；后台与小程序截图分开说明。
- 问题记录用统一状态：`待处理` / `待确认` / `已修复·待复验` / `环境说明`。
- 文档版本从 V0.1 起，修复或补图后升版并在“版本记录”写明。
