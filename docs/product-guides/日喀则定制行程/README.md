# 日喀则行程定制全流程操作指引

以「定制包车 · 5 座越野 · 1 车」为例，覆盖需求提交 → 分配负责人 → 方案编制 → 冻结与客户确认 → 原子转单与支付 → 派车履约 → 变更/取消 → 供应与成本 → 结算售后。

## 文件

- `日喀则行程定制全流程操作指引（评审稿）.docx`：正式评审稿（含 8 张截图）。
- `assets/`：后台与小程序截图，按流程编号。
- `问题记录.md`：本次走单实际遇到的问题、影响与建议修复项。
- `content.py` / `build_doc.py`：文档内容与生成脚本；改内容后重新生成 docx。
