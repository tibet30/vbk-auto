# 日喀则区域接送全流程操作指引（和平机场示例）

以「日喀则→和平机场（接送）」为例，覆盖产品与直接价格 → 用户填行程 → 支付 → 接单审批 → 派车 → 到场等候 → 接客送达 → 运营核对 → 财务 → 延误/未到/故障售后。

## 文件

- `日喀则区域接送全流程操作指引（和平机场示例·评审稿）.docx`：正式评审稿（含 8 张截图）。
- `assets/`：后台与小程序截图，按流程编号。
- `问题记录.md`：本次走单实际遇到的问题、影响与建议修复项。
- `content.py` / `build_doc.py`：文档内容与生成脚本；改内容后重新生成 docx。
