# 日喀则自驾租车全流程操作指引

以「日喀则自驾租车 · 5 座越野」为例，覆盖产品与车辆价格 → 用户选车 → 支付 → 接单与资质 → 取车交接 → 租用中 → 还车交接 → 即时费用与押金 → 违章观察与最终结算。

## 文件

- `日喀则自驾租车全流程操作指引（评审稿）.docx`：正式评审稿（含 9 张截图）。
- `assets/`：后台与小程序截图，按流程编号。
- `问题记录.md`：本次走单实际遇到的问题、影响与建议修复项。
- `content.py` / `build_doc.py`：文档内容与生成脚本；改内容后重新生成 docx。
