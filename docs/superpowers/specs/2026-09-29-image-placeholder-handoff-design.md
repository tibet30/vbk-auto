# 行程封面占位与 VBK 草稿录入

日期：2026-09-29  
状态：本地实施；尚未进行真实 VBK 上传、上架验证或部署

## 目标与边界

行程规划找不到合格封面时，在产品封面槽位放一张明确标注“运营占位图”的图片。其他资料齐全后，可以经过现有确认流程上传到 VBK，保存为**未提审、未上架草稿**。占位图一直提醒运营替换，真实封面保存并读回后才取消提醒。

这是一类缺图产品的通用处理，不针对单个 ID。`dbdca629-74df-44ab-b09c-2bae032805d1` 用于回归已有人工封面的识别，不能误加占位。人工图片的 ID 无需关联行程景点；仍需通过文件、尺寸及上传校验。

当前必填图片槽位是产品封面。行程 `spots[].images` 继续只存真实图库图片，不塞占位数据。不改变找图候选匹配和质量规则。

## 触发与状态

- 只有没有可用人工或图库封面时才设 `presentation.coverFallback`。它包含固定 `slotKey`、`assetKey`、`reason`、`createdAt`，远端上传成功后可记录 `remoteImageId` 便于恢复。
- 搜索穷尽且候选均不合格时用 `no_qualified_candidate`；图库超时、鉴权或接口故障用 `search_unavailable`，保留重试语义，不宣称图库没有合适图片。
- 再次规划、重查和应用重启使用持久化标记；已保存真实封面始终优先。人工上传或图库选图保存成功后清除占位标记和替换提醒。
- 生成占位时将 `commercial.release.submitReview` 和 `publishAfterApproval` 均设为 `false`。两项只要不明确为 `false`，就绪和录入入口均拒绝使用占位图。

## 图片与上传

应用内置横版 PNG `cover-fallback.png`，尺寸 1586 × 992，低于 8 MiB；图中直接写“运营占位图”“请替换为真实图片”“仅供草稿录入 · 禁止上架”。运行时检查 PNG 格式、至少 1280 × 800 和大小；资源缺失或不合格则在远程写入前报错。

VBK 图文阶段复用已存在的手动封面上传及远端回读流程，通过内存文件载入内置图片，避免打包后 ASAR 内的路径无法交给浏览器文件选择器。上传成功后持久化 `remoteImageId`；重试先确认已绑定图片，防止重复上传。远端只收到占位图片文件，不把 `coverFallback` 当图库 `imageId`，也不校验占位 ID 与景点的关系。

是否实际被 VBK 接受，须在真实登录会话中上传并读回才能确认；本地尺寸检查不能代替平台验收。

## 草稿与上架保护

1. 准备完成和 Agent 审批允许“占位封面 + 其他必填内容齐全 + 两个发布开关均为 false”。审批摘要明确提示仅保存未提审草稿，上架前须换图。
2. 完整录入、恢复和单阶段重试均在写入前检查两个发布开关与占位资源。图文阶段再次检查并读取资源。
3. 现有 `automationBlockers` 对提交审核或审核后发布为 `true` 的产品阻断草稿录入。占位图的独立检查又要求两项均明确为 `false`，避免缺值时默认值放行。
4. 占位标记留在本地产品中，列表、详情和 Agent 持续显示“需换图 / 禁止上架”。替换真实封面并重新检查之前，不应把该草稿当成可上架产品。

应用没有替运营控制 VBK 网站外部的人工作业。若有人绕过本应用直接在 VBK 上提审或上架，需依赖运营流程；本地代码门只覆盖本应用的自动化入口。

## 异常与恢复

| 情况 | 处理 |
| --- | --- |
| 图库不可用 | 标记待重试，可先以占位保存草稿；不误判为无合格图片 |
| 资源文件缺失、尺寸不合格 | 远程写入前失败，说明原因 |
| 平台拒绝图片或未回读唯一绑定封面 | 阶段失败并保留诊断，不宣称上传成功 |
| 上传已成功但后续步骤失败 | 持久化远端图片 ID；重试先回读并复用 |
| 真实封面上传后 Agent 仍报缺图 | 从产品持久化状态重算并清除旧问题 |
| 其他字段仍缺失 | 保留各自阻塞原因，不因占位提前批准 |

## 验收门

| 用例 | 期望结果 |
| --- | --- |
| 无合格封面，其他内容完整 | 占位显示在封面位置；可确认并保存 VBK 未提审草稿；标记持续提醒换图 |
| 占位且任一发布开关不为 `false` | 就绪和录入失败，远程写入前停止 |
| 草稿上传或阶段重试 | 使用符合尺寸的内置文件；远端图片 ID 与唯一封面绑定读回；不重复上传 |
| 已有真实人工或图库图片 | 不加占位、不覆盖、不重复提问；人工图片不做景点 ID 关联校验 |
| 图库故障 | 显示待重试，不说“没有合适图片” |
| 真实图片替换后重查 | 清除占位标记；按真实图片规则重新判断 |
| 指定回归产品 | 已保存人工封面仍被识别为有效来源，无错误占位 |

本地自动化测试、类型检查和构建只能证明代码路径与资源打包情况。VBK 实际上传及未上架状态还需要独立远端读回，部署也需要单独授权。
